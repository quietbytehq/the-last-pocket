# Asset provenance

All table plates, material textures, original comic characters and the Crown & Cue icon were generated for this project using the built-in image tool. The base table plate derives from the original AI-generated concept reference. The portraits depict original adults in a vintage American comic illustration style, without existing named characters.

The game draws live 3D balls, rolling orientation, reflections, cue, shadows and animated aiming over a fixed illustrated table plate. Carom uses procedural 3D geometry. Ball skins, interface badges, small SVG icons and stereo impact effects are procedural project assets. Original project code and visual/effect assets are licensed under Apache-2.0.

The table production prompt is in docs/table-v2-prompt.txt. Character and table-upgrade prompts are in docs/campaign-art-prompts.json. Rival dialogue is in data/rivals.json and docs/RIVAL_VOICE_LINES.csv. The final app icon is the Crown & Cue design selected for The Last Pocket.

Fonts and music have separate terms, recorded in NOTICE and LICENSES. Screenshot images in docs are actual game renders with staged test positions.
